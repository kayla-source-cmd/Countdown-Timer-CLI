# Countdown Timer CLI

A simple Python command-line application that counts down from a number of seconds entered by the user.

## Features
- Allows users to enter countdown duration.
- Counts down one second at a time.
- Displays a message when the timer finishes.

## Technologies
- Python 3
- time module
- while loops

## How to Run

```bash
python3 countdown_timer.py
```
